# RecoMart Recommendation Pipeline

End-to-end data management pipeline for an e-commerce recommendation system.

## Assignment Objective

Design and implement a complete data management pipeline for a recommendation system. The pipeline covers ingestion, raw storage, validation, preparation, transformation, feature management, model training, experiment tracking, orchestration, and inference.

## Tech Stack

- Python
- DuckDB
- Great Expectations
- DVC
- MLflow
- Prefect
- Streamlit / FastAPI
- Docker

## Pipeline Stages

1. Problem formulation
2. Data collection and ingestion
3. Raw data storage
4. Data profiling and validation
5. Data preparation and EDA
6. Feature engineering and transformation
7. Feature store
8. Data versioning and lineage
9. Model training and evaluation
10. Pipeline orchestration
11. Demo interface

## Data Sources

- Retailrocket e-commerce dataset
- DummyJSON product/user/cart API

## Main Evaluation Metrics

- Precision@K
- Recall@K
- NDCG@K
- Hit Rate@K
